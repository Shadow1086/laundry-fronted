# 易净洗护微信小程序

这是易净洗护一期用户端微信小程序原型，围绕“下单—智能柜存衣—商家清洗—返柜—付款取衣”的业务闭环设计。

## 当前页面

- 登录：微信资料选择、手机号授权登录，以及开发环境显式演示登录
- 首页：门店下单、扫码开柜、会员年卡、附近营业点
- 下单：左侧大类导航、右侧小类列表、已选衣物和页面内订单确认
- 我的：登录用户资料、会员、订单状态、常用功能和管理员入口

## 项目结构

```text
miniprogram/
  app.js                 # 小程序生命周期与云能力初始化
  app.json               # 小程序全局配置
  app.wxss               # 全局样式
  pages/                 # 登录、首页、下单、我的及业务占位页面
  components/            # 可复用 UI 组件
  api/                   # 按业务封装后端接口
  services/              # 跨接口业务流程与领域计算
  utils/                 # request、storage、format 等通用能力
  config/                # 环境配置
  constants/             # 稳定枚举和本地存储键
  types/                 # 后续 TypeScript 迁移使用的类型声明
  assets/                # 图片与图标资源
project.config.json      # 微信开发者工具项目配置
```

## 预览

使用微信开发者工具打开项目根目录，编译 `miniprogram/` 小程序。

当前界面使用本地演示数据，登录、订单、支付、智能柜和通知接口需要后续接入服务端。
